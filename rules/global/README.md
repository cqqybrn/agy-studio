# Antigravity Gemini 破甲 · 全局规则 / Global rules

| | |
| --- | --- |
| **中文名** | Antigravity Gemini 破甲 |
| **English** | Antigravity Gemini Armour Break |
| Git 源 | `rules/global/AGENTS.md` |
| 本机生效 | `%USERPROFILE%\.gemini\config\AGENTS.md` |

`npm install`、双击 `start.cmd`、后端启动与每次 run 前会自动安装；也可手动：

```powershell
npm run setup-global-rules
```

本机 **所有 agy 会话**（WebUI、CLI、IDE）共用该文件。
